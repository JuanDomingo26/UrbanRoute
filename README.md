# UrbanRoute

Proyecto de estructuras de datos

Herramienta que modela y analiza sistemas de transporte multimodal programado en Java para las grandes metropolis

Permite: 

- Cargar redes de transporte
- Modificar redes de transporte
- Ver un grafo de la red
- Detectar subredes
- Calcular la ruta de menor tiempo
- Identificar "Hubs" de transferencia
